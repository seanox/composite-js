## Reactive: Data Model Depth [reactive_depth_benchmark.html](reactive_depth_benchmark.html) updates one leaf through a reactive proxy at 1, 5, 10 and 25 nested `child` properties beneath `state.root`. Each case has just one text binding, isolating model depth from DOM size. It accumulates the times of 100 sequential updates per depth so that sub-millisecond operations do not simply round to zero in the summary. Model construction, proxy traversal for the write, initial rendering and pauses between updates are excluded; re-evaluation of the complete expression path is included. Info: Output is hidden. 100 sequential leaf updates per data model depth.
